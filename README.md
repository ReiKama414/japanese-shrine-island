# Japanese Shrine Island

互動式 3D WebGL 日本神社島嶼微縮模型——React、Three.js、React Three Fiber 與自訂 GLSL 水面著色器。

**Made with Gemini 4** 

- GitHub: https://github.com/ReiKama414/japanese-shrine-island
- Site: https://reikama414.vercel.app/

## 技術棧

- React 18 + TypeScript + Vite
- Three.js / `@react-three/fiber` / `@react-three/drei`
- Tailwind CSS（CDN）+ lucide-react
- Custom GLSL water shaders

## 啟動

```bash
npm install
npm run dev
```

建置：

```bash
npm run build
npm run preview
```

## 功能

- 鳥居／社殿／五重塔相機取景
- 晝夜平滑過渡、潮汐與水色季節預設
- 畫質等級與微調抽屜
